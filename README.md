Este projeto foi desenvolvido como **atividade em aula** na faculdade.
O objetivo é realizar a **contagem de estoque**, calcular o **valor unitário** dos itens e comparar os resultados entre **Estoque A** e **Estoque B**.

## 📊 Funcionalidades
- Registro de produtos e quantidades
- Cálculo automático do valor unitário
- Comparação entre Estoque A e Estoque B
- Relatórios simples para análise
